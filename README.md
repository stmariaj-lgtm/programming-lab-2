# Лабораторна робота №2. Лінійні програми та арифметичні вирази

Номер у журналі K = 20. Для N від 1 до 5 номер виразу дорівнює ((N³ + K²) mod 60) + 1.

| N | № | Вираз |
|---|---|---|
| 1 | 42 | $1/\sqrt{ax^2+bx+c}$ |
| 2 | 49 | $\tan(a)\cos(2x)/a$ |
| 3 | 8 | $\ln(\lvert\cos x\rvert)/\ln(1+x^2)$ |
| 4 | 45 | $\lvert x\rvert/\lvert x+1\rvert$ |
| 5 | 46 | $b\sqrt[b]{a}/a$ |

Ввести x, a, b, c один раз через пробіли. Кути задані в радіанах. Десятковий роздільник — крапка. Якщо один із виразів не визначений, програма переходить до наступного.

Для введення `1 1 1 1` результати за порядком становлять **0.5774, −0.6481, −0.8882, 0.5000, 1.0000**.

## Запуск

У консолі Developer Command Prompt for Visual Studio відкрийте папку роботи та виконайте:

```bat
cl /utf-8 /std:c17 main.c /Fe:lab.exe
lab.exe
```

У Linux:

```sh
gcc -std=c17 main.c -lm -o lab
./lab
```
